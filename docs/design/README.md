# Auto Soccer design

The canonical design specification is [design-system.md](design-system.md). This is **Pop Arcade v0.2**, superseding the original dark navy/neon-lime concept.

The approved homepage visual reference and PDF export were produced during design exploration; add them to `assets/` and `exports/` respectively when binary assets are committed. The Markdown specification is the source of truth, and application theme tokens must match it.

Implementation: React + Tailwind + DaisyUI. Match imagery must reflect actual `autosoccer-sim` 2D footage rather than invented high-fidelity gameplay.
